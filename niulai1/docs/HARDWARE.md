| I2S 信号 | GPIO | 备注 |
|----------|------|------|

## 三、踩坑记录

| 问题 | 原因 | 解决 |
|------|------|------|
| 摄像头 I2C 不响应 | PWDN/RESET 误设为 43/44，与 LCD DC/CS 冲突 | 设为 -1，硬件上电自复位 |
| 摄像头画面雪花噪点 | 数据脚 D0-D3 V2.2 实际走线与 test_camera.c 不同 | 改为 D0=11, D1=9, D2=8, D3=10 |
| 屏幕初始化后黑屏 | LCD 背光引脚误判为 GPIO 控制 | 背光实际直连供电，无需 GPIO |
| 麦克风音量极低 (~500) | WS 时钟极性配置错误 | 改用 WS=norm（非反转），峰值恢复至 27372 |
| HTTP JSON 过大崩溃 | 2 秒录音的 WAV+Base64 超过 HTTP buffer | 稳定使用 1 秒录音，无 WAV 头 |
| MiMo ASR 返回"嗯。" | 初始录音长度和时机不匹配说话速度 | 绿灯准备期 + 1 秒录音 + 独立 ASR 模型 |
| 构建系统崩溃（CMake 缓存损坏） | 反复修改依赖导致 build 目录锁定 | 使用 build2 目录，正确 TOOLCHAIN 路径 |
| 开机音/TTS 无声 | TF 卡槽 J2 飞线脱落（板子搬运震断） | 补焊 J2 焊点；A/B 测试（旧固件+本地测试音）实锤硬件故障，与代码无关 |

## 四、构建环境

| 工具 | 版本 | 路径 |
|------|------|------|
| ESP-IDF | v5.2.2 | `C:\Users\21595\esp-idf` |
| 交叉编译器 | xtensa-esp-elf 13.2.0 | `C:\Users\21595\.espressif\tools\xtensa-esp-elf\...` |
| Python | 3.13 | `C:\Users\21595\.espressif\python_env\idf5.2_py3.13_env` |
| esptool | v5.3.1 | 随 IDF 安装 |

**构建命令（Git Bash 环境）:**
```bash
export IDF_PATH="/c/Users/21595/esp-idf"
export PATH="/c/Users/21595/.espressif/tools/xtensa-esp-elf/esp-13.2.0_20230928/xtensa-esp-elf/bin:/c/Users/21595/.espressif/tools/cmake/3.24.0/bin:/c/Users/21595/.espressif/tools/ninja/1.11.1:/c/Users/21595/.espressif/python_env/idf5.2_py3.13_env/Scripts:$PATH"
cd firmware-esp32/build2
cmake .. -G Ninja -DCMAKE_TOOLCHAIN_FILE=C:/Users/21595/esp-idf/tools/cmake/toolchain-esp32s3.cmake -DTARGET=esp32s3 -DIDF_TARGET=esp32s3
cmake --build .
```

**当前固件大小**: ~902KB，分区 2MB，剩余 56%。
