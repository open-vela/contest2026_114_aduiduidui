## 一、外接 MAX98357A 功放(唯一需要动手接线的地方)

板上没有音频输出电路,喇叭全靠外挂。I2S1 复用 SD 卡槽三根线(SD 功能固件未用,演示不插卡):

| MAX98357A 模块脚 | 接到板子 | GPIO | 说明 |
|---|---|---|---|
| **BCLK** | SD 卡槽 CLK 脚 | **GPIO39** | I2S 位时钟 |
| **LRC / WS** | SD 卡槽 CMD 脚 | **GPIO38** | I2S 左右声道时钟 |
| **DIN** | SD 卡槽 D0 脚 | **GPIO40** | I2S 数据输出 |
| **VIN** | 3V3 | — | 供电 |
| **GND** | GND | — | 共地 |
| **SD**(模式脚) | 3V3 常开 | — | 直接拉高使能,不占 GPIO |
| 喇叭 + / - | MAX98357A 输出端 | — | 3W 8Ω 小喇叭 |

- 三根 I2S 线就焊在板子背面的 SD 卡槽焊盘上(飞线)
- ⚠️ 演示期间**禁止插 TF 卡**(SD 槽引脚与 GPIO 直连,插卡会电气冲突)

代码依据:`firmware-esp32/main/voice.c:140`(bclk=39 / ws=38 / dout=40,24kHz I2S 标准模式)

## 三、踩过的坑(师傅接线时留意)

1. 摄像头 PWDN/RESET 千万别设成 43/44(和 LCD 的 DC/CS 打架),固件里是 -1
2. V2.2 的摄像头数据脚 D0-D3 走线是 11/9/8/10,**不是**例程里的 8/9/10/11 顺序
3. 麦克风 WS 极性要 norm(不反转),否则音量只有 ~500
