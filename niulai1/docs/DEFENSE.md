## 一、项目概述

**智瞳·伴读** 是一台 AI 儿童阅读陪伴终端：把普通绘本放在设备摄像头下，设备拍照上传云端识别书页内容，用自然语音朗读讲解；孩子可按键提问对话。屏幕上住着一只"阅读精灵"，随阅读进度成长升级，把阅读变成游戏，为双职工家庭减轻陪读压力。

### 语音架构（自研核心）

- **单写者队列**: 开机提示音 / TTS 播放 / 测试音全部经 `voice_task` 一条队列,
  从根上消灭多任务并发写 I2S 的死锁与竞态
- **代际抢断**: 新语音到达即打断旧语音（≤21ms 响应）, 孩子连续提问优先回答
- **爆音抑制**: 播完补 ~100ms 静音帧让 DAC 平滑归零再停时钟, 无尾音"咕噜"
- **本地开机音**: C5-E5-G5-C6 上行琶音 1 秒, PCM 本地合成, 不依赖网络,
  兼做音频链路硬件自检（串口日志 + 人耳双通道确认）

## 四、创新点（答辩重点）

1. **硬件零改线音频复用** — 纯视觉板 ESP32-S3-EYE 无音频电路,
   借道板载 SD 卡槽的三根走线（IO39/38/40）引出 I2S1 接 MAX98357A,
   不破坏板子任何功能
2. **本地合成开机音 = 硬件自检** — 开机琶音不依赖网络与云端,
   上电即验证「代码→I2S→功放→喇叭」全链, 现场调试神器
3. **图传弱网自适应五件套** — 实测环境会周期性丢大 TCP 段: ①MSS 降到 536（小段存活率高）
   ②WiFi/LWIP 内存卸载进 PSRAM（省内部 RAM）③TCP 收发缓冲提到 16KB ④推流降到 5fps 限速
   ⑤send 遇 EAGAIN 不再直接关连接, 改 5ms 间隔重试（1s 上限）。网页侧断线 1.5s 自动重连;
   诊断日志带 errno 与栈高水位 hw=, 现场排障可读。实测 346 帧零中断
4. **软件 AES 定案** — HW AES + PSRAM TLS 缓冲会耗尽 DMA 池,
   改软件 AES 后 HTTPS 全链稳定, 代价仅一点 CPU
5. **单写者语音架构** — 所有发声走一条任务队列 + 代际抢断,
   无死锁、无竞态、无爆音, 孩子抢问体验顺滑
6. **成长激励闭环** — XP 变化 → NVS 持久化 → 狐狸升级换图 + 弹跳动画,
   断电平级不丢; 情绪状态机实时流转, 以 Mood 文字呈现 (表情图未接入, 如实说明)
