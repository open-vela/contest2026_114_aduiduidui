# 护眼提醒 Skill

## 触发条件

- 连续阅读/使用时长达到 25 分钟（由 cron_service 定时任务触发）
- 家长主动询问"今天读了多久"

## 执行流程

1. **提醒**：TTS 播放柔和提醒（如"已经读了 25 分钟啦，眼睛要休息一下哦"）
2. **引导**：口播带领 30 秒简易眼保健操（闭眼数数 → 看远 → 看近 → 转眼球）
3. **精灵动画**：切换阅读精灵到休息/做操动画，休息结束恢复
4. **计时复位**：确认孩子休息后重置累计阅读时长

## 约束

- 提醒语气友好，不使用命令式口吻
- 每 25 分钟最多提醒一次，孩子明确拒绝时本次不强推
- 休息引导总时长 ≤ 60 秒
