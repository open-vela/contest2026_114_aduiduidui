# 绘本伴读 Skill

## 触发条件

满足任一即触发：

- 摄像头画面中检测到绘本/书本类物体（大面积纸张 + 图画/文字）
- 孩子说出"给我讲讲这本书""读一下""这是什么"等请求
- 孩子用手指着画面中的某个物体提问

## 执行流程

1. **拍照识别**：调用摄像头对当前画面拍照，提取文字与主要画面元素
2. **理解场景**：结合对话上下文判断孩子意图——是想听全文、听讲解、还是问某个细节
3. **生成内容**：
   - 语言适合 3~8 岁儿童：短句、具体、生动
   - 每次讲解控制在 2~4 句，不照搬书页原文
   - 提问式结尾引导互动（如"小兔子为什么哭了呢？"）
4. **朗读输出**：调用 TTS 朗读生成内容（音色：冰糖）
5. **联动精灵**：讲解开始时显示阅读精灵倾听动画；讲解结束根据互动质量增加经验值

## 约束

- 回答始终面向儿童，避免成人化表达与说教
- 单次朗读 ≤ 30 秒；长绘本自动分页讲解
- 孩子连续提问时优先回答，打断当前朗读
- 内容不得出现暴力、恐怖等不适龄情节渲染
- 讲解与朗读之间无需询问确认，直接执行
